# The fonts I use in UX / UI projects.


 <img src="personal_.png" alt="Personal Fonts">

A curated collection of my favorite typography resources used in my daily UI/UX design workflow.

## 🚀 How to Use

1. Clone this repository or download it as a ZIP file.
2. Open the `Fonts` folder.
3. Install the font files on your operating system (macOS/Windows) to make them available in design tools like Figma, Sketch, Photoshop, or Illustrator.

## ⚠️ Disclaimer & Licenses

This repository serves as a personal backup and reference for my design workflow. **All fonts belong to their respective creators and foundries.**
